# CURVE プロダクト仕様（MVP）

## 目的

公道を安全に走るドライバーが、道の特徴と休憩・目的地を把握し、余裕を持ったドライブ計画を立てられるようにする。

## 利用モード

### ワインディング

- 峠・ワインディングを地図とリストから探す。
- 詳細では開始／終了地点、距離、所要時間、標高差、代表的なコーナーのR（目安）、道路幅、離合の目安を確認する。
- 「攻める」ことを促す表現、走行タイム、危険運転を助長する機能は扱わない。

### ドライブ

- 景色のよい道と、道の駅・海の駅・展望台・カフェなどを含む寄り道候補を探す。
- 詳細では景観、立ち寄り先、休憩のしやすさ、営業確認が必要な情報を確認する。

## 共通の操作

- モード切替、条件フィルタ、カードの保存、カード選択による詳細表示。
- 地図上の表示と選択中のカードを同期する（MVPでは概念地図）。
- 画面下部に安全運転の注意を常時提示できる。

## データと安全性

- 現在のデータはUI検証用のサンプル。実運用では自治体・道路管理者・公式施設情報などの出典、確認日、利用者報告の審査状態を持つ。
- 通行止め、工事、規制、施設営業時間はリアルタイムまたは出発直前の確認が必須。
- 道路幅やコーナーRは走行を保証するものではなく、天候・交通量・季節で大きく変わる参考情報として表示する。

## MVP外

- ターンバイターン案内、GPS追跡、アカウント同期、投稿・モデレーション、リアルタイム交通・規制連携。
